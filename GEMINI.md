## Automatic GitHub & Lovable Sync

> [!IMPORTANT]
> **AUTONOMOUS SYNC TO GITHUB & LOVABLE (MANDATORY)**:
> All changes completed and verified by the assistant MUST be automatically committed and pushed to GitHub without asking for user approval or confirmation:
> 1. After completing code or configuration edits, verify build/types if applicable.
> 2. Automatically stage the relevant files (`git add <files>`).
> 3. Automatically commit with a concise, descriptive message (`git commit -m "..."`).
> 4. Automatically push to the remote branch (`git push origin main`).
> 5. Never rewrite published git history (do not use `--force`, `--amend` on pushed commits, or destructive rebases).
